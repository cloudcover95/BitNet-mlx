# Inference Slice Checklist

Pre-push checklist for each additive slice on BitNet-mlx. Companion to INFERENCE_SLICE.md, which stays unchanged.

1. Pull main. Confirm a clean tree.
2. Pick a brand-new path. Confirm it does not exist.
3. Add exactly one file. Do not edit or delete existing files.
4. No .github/workflows changes.
5. No model weights or downloads.
6. One commit, one push to main. Record the SHA.
